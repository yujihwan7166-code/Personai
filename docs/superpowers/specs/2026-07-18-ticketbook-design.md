# 티켓북 — 엔터테인먼트 기록집

작성 2026-07-18 · 신규 방 `/tickets`

## 컨셉

영화·드라마(넷플릭스 포함)·책·게임·연극 등 "본 것"을 기록하는 방. 기록 하나 =
티켓 한 장. 핵심 설계 원칙 세 가지:

1. **입력 마찰 최소** — 제목만 치면 나머지는 자동으로 붙는다 (API 우선, AI 보완)
2. **티켓 메타포** — 절취선·스탬프·관람일이 있는 티켓 반쪽이 시각 정체성
3. **수집의 재미** — 압박(스트릭·못 채운 주) 없이 모으는 재미만

건강기록에서 게임화를 제거한 전례가 있으나, 이 방은 "수집" 자체가 컨셉이므로
수집형 라이트 게이미피케이션을 채택한다. 목표·스트릭형 장치는 넣지 않는다.

## 정체성

- 라우트 `/tickets`, 방 이름 "티켓북"
- 테마: **미드나이트 네이비 + 앰버** (어두운 극장 + 영사기 불빛). 포스터의
  다채로움을 받치는 차분한 배경. 인맥노트 테라코타·데일리로그 세이지·건강
  그린과 구분됨
- 사이드바: 캐논 v2 (아이브로우+제목+부제+날짜칩 · 검색 · 아이콘 내비 ·
  활성=채움 알약 · 푸터)
- 마스트헤드: "티켓북" 27px + 실데이터 한 조각 (`올해 23편 · ★3.9`)

## 데이터 모델

```ts
type TicketKind = 'movie' | 'tv' | 'book' | 'game' | 'stage';

interface TicketEntry {
  id: string;
  kind: TicketKind;
  title: string;
  creator: string;        // 감독/저자/개발사/극단
  year?: number;
  posterUrl?: string;     // TMDB·카카오 이미지 URL (핫링크, 저장 안 함)
  rating: number;         // 0.5 ~ 5, 0.5 단위
  watchedAt: string;      // 로컬 YMD 'YYYY-MM-DD' (여행기록 교훈: UTC 금지)
  where?: string;         // 극장 / 넷플릭스 / 종이책 / 전자책 / …  (kind별 프리셋 + 자유입력)
  oneLiner: string;       // 한줄평
  longNote?: string;      // 접힌 섹션 — 긴 감상
  quotes?: string[];      // 명대사·인용
  rewatch: boolean;       // 재관람/재독
  genres?: string[];      // API·AI가 채움 (컬렉션 스탬프 판정용)
  createdAt: number;
}

interface TicketStore {
  entries: TicketEntry[];
  yearGoal?: { year: number; count: number };  // 연간 목표 (선택)
}
```

localStorage `ticketbook.v1`. 포스터는 URL만 저장하고 이미지 로드 실패 시
티켓형 폴백 카드(kind 색 + 제목 타이포)로 대체 — 오프라인에서도 화면이 성립한다.

## 입력 플로우 (핵심)

`+ 티켓 추가` → 검색창 하나에서 시작.

1. **API 검색** — kind가 movie/tv면 TMDB 통합검색, book이면 카카오 책 검색.
   결과 목록(포스터 썸네일 포함)에서 고르면 포스터·감독/저자·연도·장르 자동 장착
2. **AI 채움 폴백** — 결과가 없거나 game/stage면 "AI로 채우기" 버튼. 기존
   gemini 헬퍼로 제작자·연도·장르를 채움 (포스터 없음 → 폴백 카드)
3. **수동 마무리** — 별점 탭, 본 날(기본 오늘), 어디서(프리셋 칩), 한줄평.
   **여기까지 30초 컷.** 긴 감상·명대사는 접힌 섹션으로

### API 키

`.env`: `VITE_TMDB_KEY`, `VITE_KAKAO_KEY`. 키가 없으면 해당 검색만 조용히
비활성화하고 AI 채움으로 폴백한다. 키 부재로 앱이 죽거나 에러 화면이 뜨는 일은
없어야 한다. 키 발급 안내는 구현 시 사용자에게 전달.

- TMDB: `https://api.themoviedb.org/3/search/multi` (ko-KR)
- 카카오 책: `https://dapi.kakao.com/v3/search/book` (Authorization: KakaoAK)

## 화면 4종

### 1. 포스터 월 (홈)

- 상단 요약띠: 올해 N편 · 평균 별점 · 이번 달 M편 · (목표 설정 시) 진행률 링
- 카테고리 탭: 전체 / 영화·드라마 / 책 / 게임 / 공연 + 연도 필터
- 포스터 그리드 (호버 시 별점·제목). 포스터 없는 항목은 티켓형 폴백 카드
- "다음 뭐 볼까?" 버튼 (→ AI 추천)

### 2. 티켓 상세

클릭 시 티켓 반쪽 디자인으로 펼쳐짐 — 절취선, 별점 스탬프, 관람일, 어디서.
한줄평이 티켓 몸통, 긴 감상·명대사는 그 아래. 편집·삭제·재관람 표시 여기서.

### 3. 입력 모달

위 입력 플로우. 수정 시에도 동일 모달 재사용.

### 4. 연말결산 (라이트)

연도 선택 시: 그 해 베스트(별점순 상위), 장르 분포, 월별 편수 정도만.
무거운 차트·통계는 데이터가 쌓인 후 확장.

## 게이미피케이션 — 수집·스탬프 라이트

- **마일스톤 티켓**: 누적 10 · 25 · 50 · 100편 달성 시 특별 디자인 기념 티켓이
  컬렉션에 발급됨 (자동, 알림은 달성 순간 1회)
- **장르 컴플리션 스탬프**: 같은 장르 5편 도달 시 스탬프 (`genres` 기반)
- **연간 목표(선택)**: 사용자가 직접 설정할 때만 존재. 요약띠에 진행률 링.
  미설정이 기본값
- **넣지 않는 것**: 스트릭, 주간 목표, "못 채운 주" 표시, 리마인더 — 숙제화 방지

## AI 추천 — 온디맨드

- 홈의 "다음 뭐 볼까?" 버튼을 누를 때만 동작. 자동 노출 없음
- 별점 4.0 이상 기록(제목·장르·한줄평)을 AI에 주고 → 취향 한 줄 분석 + 추천
  5개를 모달로 표시. 교차 카테고리 허용 ("이 책이 좋았다면 이 영화도")
- 추천 항목에 "티켓북에 담기" → 입력 모달이 제목 프리필 상태로 열림
- 기록이 3편 미만이면 버튼 비활성 + "3편만 기록하면 취향을 분석해드려요"

## 새 방 등록

아카이브 방 스펙의 등록 지점 실측 목록을 그대로 따른다 (라우팅 · 메인 메뉴 ·
방 목록 · 마스트헤드 · 사이드바 캐논 · 색 토큰 · 오늘의 나 연동 여부).
오늘의 나 대시보드 연동은 이번 범위에서 제외 — "이번 주 본 것" 한 줄은 추후 후보.

## 구현 단위

- `src/pages/Tickets.tsx` — 방 진입점 (화면 4종 조립)
- `src/lib/tickets/ticketStore.ts` — 모델·localStorage·마이그레이션 스텁

- `src/lib/tickets/milestones.ts` — 마일스톤·스탬프 판정 (순수 함수, 테스트 대상)
