# 가계부 방 설계 (2026-07-21)

## 정체성

- **이름**: 가계부 · **라우트/id**: `ledger` (메뉴 '정리' 축의 기존 준비 중 자리를 실물로 교체)
- **테마**: 딥 네이비 (기존 방과 미중복 — 데일리로그=세이지그린, 건강=그린, 인맥=테라코타, 위키=플럼, 커리어=레드)
- **컨셉**: "흐름(가계부) + 잔고(자산) = 월 결산으로 이어지는 내 돈의 기록"
  - 가계부 = 손익계산서(매일, 수입−지출), 자산 = 대차대조표(월 1회 스냅샷, 순자산)
  - 접점 = 월 결산: "이번 달 남은 돈이 순자산이 됐다"는 스토리
- **경쟁 상대**: 토스·뱅크샐러드가 아니라 **자산관리 스프레드시트**. 실시간·자동연동 포기를 컨셉으로 승화한 "월말 결산 장부"
- **1원칙**: 입력이 쉬워야 한다. 복잡도가 이 원칙과 충돌하면 복잡도를 버린다.

## 왜 우리 걸 쓰나 (토스가 못 하는 것)

1. AI 한 줄 입력 — "어제 택시 12000 커피 4500" 한 줄로 끝
2. 은행에 안 찍히는 돈 — 현금·더치페이 실부담액·상품권
3. 광고·금융상품 추천 없음 — 순수 기록
4. 순자산 스토리 — 수입→지출→저축→자산으로 이어지는 구조를 한 방에서

제약(정직하게): 계좌·증권사 자동연동 불가(마이데이터 라이선스), 실시간 시세 불가. 수동 입력 지속률이 최대 리스크 → 입력 마찰 제거에 전력.

## 골격

캐논 사이드바(아이브로우+제목+부제+날짜칩, 활성=채움 알약) + 6섹션.
마스트헤드: "가계부 27px + 실데이터 한 조각" (예: "이번 달 −842,000원").

| 섹션 | 내용 | 단계 |
|---|---|---|
| 🏠 대시보드 | 위젯 그리드 + AI 채팅바 | 1차 |
| 📒 내역 | 월별 수입·지출·이체 리스트, 필터·검색, 정식 상세입력 폼 | 1차 |
| 🎯 예산 | Monarch식 3버킷(고정/변동/비정기) 월 예산 + 페이스 | 1차 |
| 🔁 고정지출 | 반복 규칙 관리, 매월 자동 기록 | 1차 |
| 💎 자산 | 보유 목록 + 월말 스냅샷, 자산 도넛, 배당 캘린더 | 2차 |
| 📊 월 결산 | 월별 리포트 아카이브 + 연말 Wrapped | 2차 |

## 입력 (핵심 축)

- **AI 채팅바**: 화면 하단부 플로팅(완전 바닥 아님), 방 전체 상주
  - 입력: `점심 김밥 4500` → 오늘·식비·4,500 / `어제 택시 12000 커피 4500` → 2건 분리·날짜 귀속 / `엄마 생신 선물 15만` → 경조사 / `넷플 17000 매달` → 고정지출 / `적금 50만` → 이체 / `삼전 10주 7만2에 삼` → 자산(2차)
  - 질의: "이번 달 커피 얼마 썼어?" → 답변 카드가 채팅바 위로 떠오름(전체 로그는 아이콘으로 대화 시트)
- **파싱 엔진**: 로컬 규칙 파서 우선(금액·상대날짜·키워드 사전) → 애매한 것만 기존 AI 키로 LLM 폴백. 자연어 질의는 LLM
- **신뢰 = 고치기 쉬움**: 저장 직후 결과 칩(날짜·카테고리·금액) 표시, 탭 한 번으로 인라인 수정
- **원탭 칩**: 자주 쓰는 지출 2~4개("☕ 아침커피 4,500")를 채팅바 위에
- **자동완성 학습**: 사용자의 분류 수정을 로컬 사전에 반영(LLM 불필요)
- **정식 폼**: 상세입력이 필요한 경우 병행

## 데이터 모델

- `LedgerEntry`: 타입(수입/지출/**이체**), 금액, 날짜(로컬 YMD 필수), 카테고리, 결제수단(현금/카드/이체), 메모, 더치페이 실부담액(총액 별도 기록)
- `RecurringRule`: 고정지출 반복 규칙(주기·금액·카테고리)
- `Budget`: 3버킷(고정/변동/비정기)별 월 예산
- `Asset`(2차): 종류(현금·예적금 / 주식·ETF·채권 / 코인 / 부동산·차·기타 / **부채(음수)**), 종목·수량·평단 또는 평가액
- `AssetSnapshot`(2차): 월말 평가액 기록 → 순자산(자산−부채) 추이
- 카테고리: 기본 10개(식비·카페·교통·쇼핑·구독·의료·주거·경조사·여가·기타) + 커스텀 추가
- 저장: localStorage(meta) — **JSON 내보내기/가져오기 1차 필수** (돈 데이터 유실 방지)

## 대시보드 위젯

1차: ① 이번 달 결산 카드(수입−지출=남은 돈, 전월 대비) ② 예산 페이스("이 속도면 월말 42만") ③ 카테고리 도넛 ④ 지출 히트맵 캘린더(금액 표시 토글) ⑤ 다가오는 고정지출 ⑥ **카드 청구 예정액**(이번 달 카드 사용액=다음 달 빠질 돈, 결제일 설정 1개 선택) ⑦ AI 브리핑 카드

2차 추가: ⑧ 순자산 추이 라인 ⑨ 자산 도넛 ⑩ 배당 캘린더

## AI 브리핑 (뱅크샐러드 금융비서의 우리식)

- 말투: **담백한 사실형** — "이번 주 식비가 평소의 1.8배, 배달이 주요인". 잔소리·응원 없음
- 엔진: 규칙기반 우선(전월 대비 카테고리 증감, 요일별 패턴 등), AI는 온디맨드
- 인사이트 소스: 두 기간 비교(카테고리별 증감), 요일별 집중("지출의 40%가 금요일"), 예산 페이스 이탈

## 후잉 체리피킹 (채택분)

| 후잉 기능 | 우리식 변형 |
|---|---|
| 복식부기의 자산 이동 개념 | **이체 타입** (지출 왜곡 방지 + 저축률 확보) |
| 신용카드 위젯·결제일 | 카드 청구 예정액 위젯 + 결제일 설정 1개 |
| 자산부채 | 부채 항목(음수 자산) → 순자산 정직화 (2차) |
| 기간손익 | 월별 수입/지출 6개월 막대 (월 결산, 2차) |
| 두 기간 비교 | 월 결산 전월 대비 증감 표 + AI 브리핑 엔진 |
| 요일별 수익/비용 | AI 브리핑 인사이트 소스로만 |
| 나는 달력이다 | 히트맵 캘린더 금액 표시 토글 |
| 기간내 월별 금액(피벗) | 카테고리×최근 6개월 표 (월 결산, 2차) |
| 아이템 워드클라우드 | 연말 Wrapped의 한 장면 |

기각: 복식부기 입력 방식, 계정과목 트리, 현금흐름표 영업/투자/재무 세분화, 트리맵·원형트리·방사형 차트, 섹션 다중 장부 — 전부 "입력이 쉬워야 함" 원칙 또는 flat 카테고리 구조와 충돌.

## 시세 (2차)

- 기본: 보유 내역 수동 입력 + 현재가 수동 갱신(월말 스냅샷 리듬)
- 옵션(2차 이후): 해외 종목만 유저 발급 무료 API 키(Finnhub 등)로 지연 시세 — 티켓북 TMDB 방식. 국내 종목은 브라우저 CORS 제약으로 수동 유지

## 제외 (YAGNI 확정)

계좌·증권사 자동연동 / 실시간 시세 / 영수증 OCR / 목표저축·습관장치(방침) / 크로스룸 연계(사용자 결정) / 공유 가계부 / 복식부기

## 구축 단계

- **1차**: 대시보드(위젯 ①~⑦) + 내역 + 예산 + 고정지출 + AI 채팅(파싱·질의) + JSON 백업 + 새 방 등록(아카이브 방 메모의 등록 지점 목록 참조)
- **2차**: 자산(전 종류+부채) + 월 결산(리포트·비교표·피벗·Wrapped) + 위젯 ⑧~⑩
- 1차 출시 후 실사용 피드백으로 2차 조정
