# 마스트헤드 양식 — "제목은 주어, 실데이터가 서술어"

워크스페이스 방 좌측 상단 공통 문법 (2026-07-13 확정).

굵은 도구명이 홀로 있으면 미완성 헤더처럼 어색하다. 플래너가 자연스러운 이유는
제목(주어) 옆의 기간 라벨(서술어)이 헤더를 "말이 되는 문장"으로 만들기 때문 —
이 문법을 모든 방에 일반화한다.

## 공식

```
[도구명 h1] + [그 방의 살아있는 실데이터 한 조각]
```

- **도구명**: `font-sans text-[27px] font-bold leading-none tracking-[-0.02em]` + 방 색 틴트(또는 기본 잉크).
  아이콘 없음(레일 마크가 담당), 부제·영문 아이브로우 없음.
- **맥락 조각**: 장식 금지 — 반드시 **실데이터**(매일/사용할수록 변하는 값)여야 한다.
  정보이자 디자인이 되고, 방이 살아있다는 감각을 준다.

## 방별 적용 현황

| 방 | 조각 | 형태 |
|---|---|---|
| 통합 플래너 | 현재 기간 | 제목 옆 텍스트 `· 7월 13일 주` |
| 올인원 노트 | 노트 권수 | 제목 옆 tabular `8권` (`text-[13px] font-bold tabular-nums text-muted-foreground/55`) |
| 데일리로그 | 오늘 날짜 | 우측 **일력 한 장** — 흰 카드 + 세이지 월 밴드 + 큰 날짜 + 요일, `rotate-[3deg]` |
| 마이커리어 | 이룬 것 N건 | 검인(檢印) — 이중 테두리 인장 + 큰 숫자 (버밀리온, `rotate-[3deg]`). 0건이면 "기록 중" 문구 |
| 마이위키 | 문서 수 | 제목 옆 tabular `36쪽` |

숫자 조각은 **단위를 반드시 붙인다** (`8` ✗ → `8권` ✓) — 맨 숫자는 무슨 수인지 읽히지 않는다.

## 새 방 추가 시

1. 도구명은 27px 캐논 그대로 (색은 방 액센트, 레일 마크와 짝).
2. 그 방에서 가장 의미 있는 "살아있는 숫자/상태" 하나를 골라 **제목 옆 숫자** 또는 **우측 스탬프**로.
   - 옆 숫자: 개수형 데이터 (노트 권수, 문서 수, 사람 수 …) — `items-baseline gap-1.5`.
   - 스탬프: 날짜/상태형 데이터 — 방 액센트 테두리 2px + 3~4도 기울임 + `mix-blend-multiply`.
3. 조각은 반드시 하나만 — 둘 이상이면 다시 어수선해진다.
