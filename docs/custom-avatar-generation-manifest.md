# Custom AI Avatar Generation Manifest

This manifest defines the first production batch for improving the custom model selection screen avatars.

## Global Art Direction

- Format: 16:9 landscape card illustration, centered subject with enough background context for the right-side detail panel.
- Style: polished semi-realistic anime illustration, clean line art, soft cinematic lighting, bright web-app friendly colors.
- Quality bar: role must be readable within one second from the thumbnail.
- Avoid: text, watermark, logos, childish flat icon style, pure photorealism, repeated identical face, repeated identical frontal smile.
- Composition: one primary person unless the role needs a small animal/object; role-specific clothing, tools, and workplace cues must be visible.
- Diversity: vary gender presentation, apparent age, face shape, hair length, pose, camera angle, and hand/object placement across adjacent cards.
- UI safety: keep the face and main role prop inside the center 70% of the image; avoid important details at the far edges.

## Prompt Template

Use this template when generating each image:

```text
Create a high-quality polished semi-realistic anime-style character illustration, 16:9 landscape, for a web app custom AI avatar card.
Subject: {visual brief}
The profession or role must be instantly recognizable through clothing, props, and background.
Use a distinct face, hairstyle, pose, and age impression compared with the other avatars in this batch.
Style: clean line art, refined web-novel/game illustration quality, soft cinematic lighting, bright but natural colors, detailed background cues, not photorealistic, not childish flat icon style.
Composition: centered upper-body character, role prop clearly visible, background softly detailed, card thumbnail readable.
No text, no watermark, no logo.
```

## Batch QA Checklist

- Every id in Batch 1 has one image at the declared output path.
- Every `avatarUrl` for occupation experts points to the declared path.
- No two adjacent cards use near-identical face, hair, pose, or background.
- Thumbnail view and right-side detail view both read clearly.
- The role is identifiable without reading the card title.
- The image stays bright and polished without becoming washed out.

## Verification Commands

- Path and duplicate check for occupation avatars:
  `npm run verify:avatars:occupation`
- Temporary quality gate for occupation avatars:
  `npm run verify:avatars:occupation:quality`

The quality gate currently uses `--min-bytes=1000000` as a practical placeholder detector. It is not a final visual-quality metric, but it catches the old low-detail icon assets while high-resolution generated replacements are being added. The final completion audit still requires manual visual review for role clarity, style consistency, no readable text/logos, and enough face/pose/background variety.
