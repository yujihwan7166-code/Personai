# 칩과 "골라진 것" — 표기 규약

방마다 필터 칩의 크기·모양·색이 제각각이었다. 같은 뜻(고르는 자리, 골라진 상태)이
화면마다 다른 말로 쓰이면, 읽는 사람은 매번 처음부터 다시 배워야 한다.
아래는 이미 다수파였던 것을 규약으로 적어둔 것이다. 새로 만들 때 여기서 고른다.

## 1. "골라진 것"을 무엇으로 보여주나

역할이 셋이고, 셋은 서로 다른 표현을 쓴다. 역할이 다르면 표현이 달라야
한 화면에 여럿이 있어도 무엇이 무엇인지 구분된다.

| 역할 | 표현 | 예 |
|---|---|---|
| **내비·탭** — 어디에 있는지 | 옅은 틴트 배경 + 방 색 글자 + bold | 모든 사이드바, 모바일 내비 칩 |
| **필터 칩** — 값을 직접 고름 | 방 색으로 꽉 채움 + 흰 글자 | 인맥노트 관계 필터, 노트 태그 칩 |
| **세그먼트 컨트롤** — 보기 전환 | 옅은 홈 위의 흰 캡슐 + 옅은 그림자 | 데일리로그 최근 필터, 인맥노트 카드/리스트 |

곁들이는 규칙:

- **드롭다운을 여는 손잡이**는 필터 칩이 아니다. 값이 걸려 있으면 옅은 틴트 +
  방 색 테두리까지만 — 꽉 채우지 않는다. 손잡이가 화면에서 제일 세면 곤란하다.
- 밑줄·아래 막대는 쓰지 않는다. 이 앱에 그렇게 하는 자리가 없다.
- 활성 표현에 틴트·테두리·그림자를 **셋 다** 걸지 않는다. 둘까지.
- 채우는 색은 그 방의 색이다. 전역 `bg-primary` 로 채우면 방 색이 무너진다.
  예외: 채운 색이 바로 옆 그림·차트의 색과 짝을 이룰 때(건강기록 지표 칩).

## 2. 치수

**알약 칩** (`rounded-full`)

    height    28px 안팎  (px-3 py-1.5)
    padding-x 12px
    font      12 ~ 12.5px
    weight    비활성 500~600 / 활성 700
    묶음 gap  6px (gap-1.5)

**세그먼트 컨트롤**

    컨테이너  p-0.5, radius 8~9, 옅은 회색 홈
    칸        height 32~34px, radius 6~7px, font 12.5~13.5px

인라인 style 을 쓰는 방(가계부·티켓북)도 같은 수치를 쓴다 — 표현 수단이 다를 뿐
치수는 하나다.

## 3. 알려진 예외 (일부러 어긋난 것)

| 자리 | 무엇이 다른가 | 왜 |
|---|---|---|
| 건강기록 지표 칩 | 채우는 색이 방 색이 아니라 지표별 색 | 바로 아래 차트 선과 같은 색이어야 이어진다 |
| 티켓북 전반 | 어두운 배경 + mono 글꼴 | 실물 티켓의 인쇄를 흉내내는 방이다 |
| 선물 기록 입력줄의 줌/받음 | height 32 (34 아님) | 같은 줄의 입력칸 높이에 맞춘다 |
